# FloodLab — Python / Streamlit

Учебное интерактивное приложение для численного исследования модели последствий наводнения. Интерфейс адаптирован по предоставленному скриншоту-примеру; расчёты выполняются в Python.

## Запуск в Windows

1. Установите Python 3.10+ с https://www.python.org/downloads/ и отметьте **Add Python to PATH**.
2. Распакуйте архив.
3. Откройте терминал в папке `FloodLab-Streamlit`.
4. Выполните:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Либо запустите `run_windows.bat`.

## Возможности

- Начальные значения для 14 переменных состояния `Z1`–`Z14`.
- Редактирование десяти внешних функций времени: `Rw`, `Hw`, `Sem`, `Vhr`, `Chr`, `Sev`, `Ch`, `Hr`, `Vh`, `Lr`.
- Генерация сценария случайными значениями и сброс всех элементов формы к значениям по умолчанию.
- Численное интегрирование через `scipy.integrate.solve_ivp` (RK45).
- Таблица результатов, метрики, графики динамики, сечения по времени, корреляция рассчитанных траекторий.
- Экспорт сводки и временного ряда в CSV.
- Справочник 66 вспомогательных функций и 14 уравнений.
- Регрессионные тесты для нумерации функций, размерности системы и внешних параметров в уравнениях `Z1`, `Z6`, `Z7`, `Z10`.

## Математические ограничения и допущения

- `model.py` содержит 66 вспомогательных функций и 14 правых частей, перенесённых по сканированному PDF `Наводнения.pdf`. При визуальной сверке уравнений исправлены различия между похожими обозначениями `Sem`/`Sev`, `Chr`/`Ch`, `Vhr`/`Vh`, включая множители в уравнениях `Z1` и `Z6`.
- В исходном PDF не приведены численные начальные условия и измеренные временные ряды внешних функций. Значения `Z_i = 1` и внешние параметры `= 1` являются только демонстрационным сценарием, а не наблюдаемыми данными.
- В исходной системе нет множителя `α`. Приложение предлагает его отдельно как масштаб правых частей, чтобы исследовать поведение системы при численно очень больших производных. При `α != 1` результат относится к масштабированному сценарию, а не к буквальной исходной системе в исходном времени.
- В функциях, использующих логарифмы, дроби и корни, предполагаются положительные `Z_i`. Численная реализация использует малый положительный порог при вычислении функций, чтобы избежать недопустимых аргументов на промежуточных шагах интегратора. Это численная защита, а не дополнительная формула источника.
- Корреляционная матрица показывает корреляции рассчитанных траекторий, а не причинно-следственные связи исходной модели.
- Это учебный симулятор, не инструмент оперативного прогноза реального наводнения.

## Проверка

Из папки проекта запустите:

```bash
python -m pytest -q
```

Тесты проверяют наличие и конечность всех 66 функций, размерность системы, корректность трёх неоднозначных сочетаний внешних функций и отдельность параметра `α`. Также проверен тестовый численный запуск RK45 с демонстрационными начальными значениями.
